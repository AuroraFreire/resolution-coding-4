A small utility project that combines a calculator with tools for processing and analyzing line-based input.

## Overview
This project provides:
- A calculator capable of evaluating mathematical expressions  
- A component that reads and processes lines of input data  

It’s designed to handle basic computations while also supporting simple input parsing workflows.
